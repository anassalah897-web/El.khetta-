# يلا نخطط — نسخة ويب أولية شغّالة

## التشغيل محليًا

تحتاج Node.js 20 أو أحدث. التشغيل المحلي من دون `DATABASE_URL` يحفظ البيانات في ملف JSON، ولا يحتاج تثبيت حزم إضافية. عند استخدام PostgreSQL، ثبّت الحزم عبر `npm install`.

```powershell
cd outputs\yalla-web-app
node .\server.js
```

افتح `http://127.0.0.1:4173` في المتصفح. لإيقاف الخادم اضغط `Ctrl+C` في نافذة PowerShell.

## ما الذي يعمل

- إنشاء خطة خروجة أو رحلة داخل القاهرة أو الجيزة أو الإسكندرية.
- الميزانية الفردية: يدخل كل عضو ميزانيته عند انضمامه؛ الأنشطة المشتركة تُختار على أساس أقل ميزانية بين الأعضاء.
- الميزانية الجماعية: يحدد المنشئ ميزانية إجمالية وحجم المجموعة المتوقع؛ الأنشطة لا تتجاوز نصيب الفرد منها.
- رابط مشاركة يفتح الخطة نفسها، مع انضمام الأعضاء وإضافة اقتراحات والتصويت عليها.
- خريطة تفاعلية للمطاعم والكافيهات من OpenStreetMap، وزر اختياري لاستخدام موقع العميل.
- صور عند الطلب من Wikimedia Commons، مع اسم صاحب الصورة والترخيص ورابط صفحة الصورة.
- عند ضبط `DATABASE_URL`، يحفظ التطبيق الخطط في PostgreSQL داخل جدول `travel_plans` مع بيانات الخطة بصيغة JSONB. ينشئ الخادم الجدول والفهرس عند التشغيل.
- من دون `DATABASE_URL`، يستخدم التطبيق `data/plans.json` للتجربة المحلية.

## حدود النسخة الحالية

- هذه نسخة MVP للتجربة. رابط الخطة يسمح لأي شخص معه الرابط بالانضمام والتصويت؛ لا توجد حسابات مستخدمين أو صلاحيات آمنة حتى الآن.
- قبل فتح الموقع للناس، أضف تسجيل دخول وصلاحيات وحماية من الرسائل المزعجة. رابط الخطة وحده ليس نظام حسابات.
- بيانات المطاعم والكافيهات تأتي مباشرة من Overpass/OpenStreetMap وتُخزّن مؤقتًا في الذاكرة ست ساعات. قد تغيب بعض الأماكن أو بياناتها، والأسعار يضيفها المستخدم عند إدراج المكان في الخطة.
- الخرائط تستخدم خادم البلاطات العام لـ OpenStreetMap. يلزم إبقاء النسب ظاهرًا، واحترام سياسة الاستخدام؛ حركة مرور تجارية كبيرة تحتاج مزود خرائط مناسبًا أو خدمة مستضافة.
- الصور تُبحث عند الطلب من Wikimedia Commons. لكل صورة شروط إعادة استخدام خاصة؛ افتح صفحة الصورة وراجع الترخيص قبل إعادة نشرها خارج الموقع.
- الموقع الدقيق لا يُطلب إلا عندما يضغط العميل «استخدم موقعي»، ولا تُرسل إحداثياته إلى خادم التطبيق. عند النشر العام استخدم HTTPS.
- لا يوجد حجز أو دفع إلكتروني في هذه النسخة.

## خدمات خارجية

- Leaflet لعرض الخريطة، وبلاطات OpenStreetMap للخلفية.
- Overpass API لجلب أسماء ومواقع المطاعم والكافيهات.
- Wikimedia Commons للصور وبيانات نسبها.
- Google Fonts وصورة Unsplash لواجهة البداية.

راجع شروط كل خدمة قبل إطلاق الموقع تجاريًا أو زيادة استخدامه.

## النشر على Render

يوجد ملف `render.yaml` يجهز Web Service مع PostgreSQL في Frankfurt، ويصل `DATABASE_URL` تلقائيًا. ارفع **محتويات هذا المجلد** إلى مستودع GitHub جديد، ثم أنشئ Blueprint من Render ووصل المستودع. لا تضع كلمات مرور أو روابط قاعدة بيانات يدويًا في GitHub.

الإعداد يستخدم الخطط المجانية للتطبيق وقاعدة البيانات. لا تحتاج شراء دومين للبدء؛ Render يعطي التطبيق رابطًا عامًا، ويمكن ربط دومينك لاحقًا.

خدمة الويب المجانية قد تتوقف مؤقتًا عند الخمول. قاعدة PostgreSQL المجانية تنتهي بعد 30 يومًا؛ بعدها توجد مهلة 14 يومًا للترقية قبل حذف البيانات. استخدمها للتجربة فقط، وخذ نسخة احتياطية أو رقّ قاعدة البيانات إلى خطة مدفوعة قبل انتهاء المدة إذا أردت الاحتفاظ بالخطط.

## النشر على Cloudflare Workers وD1

أُضيف مسار نشر بديل يستضيف ملفات الموقع على Cloudflare Workers Static Assets ويحفظ الخطط في D1. ملف `worker.js` ينفذ واجهات API، والملف `database/migrations/0001_create_travel_plans.sql` ينشئ جدول الخطط. إعداد `wrangler.jsonc` جاهز بعد وضع معرّف قاعدة D1 مكان `REPLACE_WITH_D1_DATABASE_ID`.

بعد إنشاء حساب Cloudflare وتثبيت Node.js، افتح PowerShell داخل مجلد المشروع ونفّذ:

```powershell
npm install
npx wrangler login
npx wrangler d1 create yalla-plans-db
```

انسخ `database_id` الذي يظهر في النتيجة إلى `wrangler.jsonc`. ثم نفّذ:

```powershell
npm run cf:migrate:remote
npm run cf:deploy
```

يعرض أمر النشر رابط الموقع. يمكن معاينة الموقع محليًا عبر `npm run cf:dev`، مع تطبيق ترحيل قاعدة البيانات المحلية أولًا عبر `npm run cf:migrate:local`.

الخطة المجانية لها حدود استخدام، وتحتاج هذه الخطوات إلى تسجيل الدخول لحساب Cloudflare وإنشاء قاعدة D1. لا يمكن إكمال النشر الفعلي قبل تسجيل الدخول. لا تضع أسرار الحساب أو بيانات الدفع في المستودع.

## ملاحظات إضافية للبيانات

- صور Wikimedia Commons تظهر مع اسم صاحب الصورة والترخيص، لكن النتائج قد لا تتوفر لكل مكان أو تحتاج مراجعة لمطابقتها. افتح صفحة الصورة قبل إعادة نشرها خارج الموقع.
- أسعار الأنشطة التمهيدية في كتالوج الخطط أمثلة أولية تحتاج مراجعة وتحديثًا قبل إتاحتها لعملاء حقيقيين. أسعار الأماكن التي يضيفها المستخدم يكتبها بنفسه.


- تظهر اقتراحات الأماكن أولًا من غير خريطة أو إذن موقع. عند الضغط على «اعرف الطريق» تظهر خريطة الوجهة فقط، ويُطلب موقع العميل وقتها لاستخدامه كنقطة بداية اختياريًا. الاتجاهات تفتح في Google Maps عبر Maps URL دون مفتاح API.
